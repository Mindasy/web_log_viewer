# 功能介绍

Web Log Viewer 是一个纯浏览器端的日志查看与分析工具，无需任何后端服务即可运行。所有解析、搜索、过滤操作均在本地完成，数据不会离开浏览器。

## 核心功能

### 多格式文件支持

支持多种文件和压缩格式的日志读取与解析：

- 直接读取 `.log`、`.txt`、`.csv`、`.json`、`.xml` 等文本文件
- 自动解压 `.zip`、`.tar`、`.tar.gz`、`.tgz`、`.gz` 压缩包，搜索其中的文本日志文件
- 支持多文件合并查看（可混合压缩包和普通文件）

### 日志解析引擎

内置 6 种日志格式预设，支持自动检测：

- **Bracket Log** — `[2026-01-15 08:00:00,000 +0800][INFO][1234][567][WEB-API][com.example.web.UserController] 用户 admin 登录成功`
- **Log4j / Logback** — `2026-01-15 08:00:00,000 INFO [http-nio-8080-exec-1] com.example.web.UserController: 用户 admin 登录成功`
- **Log4j2** — 支持带线程上下文的多字段格式
- **Syslog** — 标准 UNIX 系统日志格式
- **Apache / Nginx** — Web 服务器访问日志格式
- **JSON** — 自动映射常见字段名（timestamp、level、message 等）
- **通用时间戳** — 备用匹配，覆盖带时间戳的任意格式

同时也支持：

- **自定义正则** — 使用命名捕获组定义自己的解析规则
- **智能规则生成器** — 自动对样本行分词并推断字段分配，所见即所得
- **Pattern 持久化** — 将常用解析规则保存到浏览器 IndexedDB，跨会话复用

### 高性能虚拟滚动表格

使用虚拟滚动技术渲染日志表格，支持百万级日志行：

- 仅渲染可视区域的行（约 20-50 行），而非全量 DOM
- 列宽可拖拽调整，支持双击自适应
- 列排序（时间戳、级别、来源等）
- 列隐藏（右键菜单或设置面板）
- 自动隐藏空字段列
- 动态自定义字段列（JSON 日志自动展开为独立列）

### 全文搜索与过滤

- **实时搜索** — 输入即搜索，支持正则模式、大小写敏感、全词匹配
- **搜索结果高亮** — 匹配文本在表格中以黄色高亮显示，当前匹配以蓝色高亮
- **搜索结果导航** — F3 / Shift+F3 快速跳转上/下一个匹配
- **级别快速过滤** — 点击级别标签切换 FATAL / ERROR / WARN / INFO / DEBUG / TRACE 可见性
- **高级过滤** — 按线程、来源、消息内容、时间范围精确过滤
- **文件源过滤** — 在文件列表中点击文件，仅显示该文件中的日志行
- **过滤相似** — 在详情面板中，根据当前消息模式自动搜索相似条目
- **排序** — 点击列头升序/降序排列

### 智能跳转系统

跳转输入框支持多种快捷语法，跳转后目标行居中显示：

| 输入 | 跳转目标 |
|------|---------|
| `42` | 原始行号 42 |
| `#5` | 当前视图第 5 行（搜索时 = 第 5 个结果） |
| `@3` | 第 3 个书签 |
| `$` | 末行 |
| `+50` | 向后 50 行 |
| `-20` | 向前 20 行 |

### 书签系统

- 双击行或 Ctrl+B 添加/删除书签
- 书签列表面板 — 显示序号和行号，点击跳转、移除
- 被过滤排除的书签灰显，点击时给出明确提示
- 书签导出 — 将书签列表导出为文件
- 清除所有书签

### 详情面板

在右侧面板中展示选中条目的每个字段值：

- 时间戳、级别、进程 ID、线程 ID、标签、来源、消息
- 自定义字段（JSON 日志或自定义正则自动提取）
- 每个字段独立复制按钮
- 操作按钮：复制整行、过滤相似、切换书签

### 统计信息

- **级别分布** — FATAL / ERROR / WARN / INFO / DEBUG / TRACE 柱状图
- **时间概览** — 日志时间跨度、平均速率
- **摘要** — 总条目数、错误数、文件大小、Top 线程、Top 来源

### 线程时间线可视化

Canvas 绘制的时间线，支持按线程/方法维度查看日志时序分布：

- **线程泳道图** — 每个线程一条泳道，按时间轴排列日志条目
- **段块模式** — 相邻条目之间画彩色矩形，形成连续时间线，直观展示流程活跃区间
- **密度模式** — 缩小时自动切换为热力图风格，适合宏观概览
- **多线程垂直滚动** — 线程数超过画布高度时自动滚动，视口裁剪保证性能
- **方法时间线**（线程详情） — 双击/Alt+点击线程标签进入，按方法名分组显示函数调用序列
- **source 格式适配** — 支持 `pkg.Class.methodName` 和 `file:func:linenum` 两种格式提取方法名
- **交互** — 滚轮缩放（Ctrl+wheel）、Shift+滚轮平移、拖拽平移、悬停高亮、点击跳转
- **右侧停靠（非模态）** — 时间线面板停靠在窗口右侧，左侧日志表格始终可见、可交互，方法/函数视图不会被关闭面板掩盖
- **点击定位** — 点击时间线条目跳转到左侧日志表格对应行（面板保留），立即查看日志
- **双向联动** — 网格选中行在时间线中以主题色圆环标记；「📌 定位当前行」按钮将时间线视图居中到当前选中行（自动打开面板）
- **点击过滤同步** — 点击线程/方法标签会同步过滤背景日志表格（线程匹配 thread/tid，方法按提取名精确匹配，不再出现空列表）；PID 选择器也同步过滤；关闭时间线面板自动恢复打开前的过滤状态
- **source 列宽度可拖拽** — 拖动标签列与绘图区之间的**可见手柄**（或双击重置）调整线程/方法名列宽度，宽度持久化保存
- **面板宽度可拖拽** — 拖动时间线面板左边缘调整面板宽度（最小 400px），宽度持久化保存
- **最小化/恢复** — 「—」按钮最小化时间线并保留视图状态，右下角悬浮按钮一键恢复；点「✕」才真正关闭（重新打开会重置）
- **主题自适应** — 画布背景、网格、文字、级别颜色全部跟随明暗主题（CSS 变量），与日志界面视觉一致
- **日期维度时间轴** — 日志跨度跨天时自动显示日期：午夜虚线分隔 + 日期标签，刻度自动切换为 `MM-dd` / `MM-dd HH:mm` 格式，彻底区分不同日期
- **进程过滤** — PID 下拉选择器，按进程号过滤时间线（支持 `pid=数字`、`[数字]` 等格式自动提取）
- **线程/方法搜索** — 实时过滤泳道，方法搜索框支持详情视图内过滤

### 视图管理

支持在搜索结果上创建视图，实现多层级过滤和回溯：

- **视图栈** — 保存当前过滤状态为视图，支持前进/后退
- **面包屑导航** — 可视化的层级路径，点击任意层级切换视图
- **视图内搜索** — 在视图数据子集上再次搜索，创建子视图
- **深度限制** — 最大 5 层，防止无限嵌套
- 加载新文件时自动清除所有视图

### 主题切换

- **暗色主题（默认）** — Tokyo Night 风格，低蓝光护眼
- **亮色主题** — 白色背景，适合明亮环境
- 偏好设置通过 `localStorage` 持久化

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + O` | 打开文件 |
| `Ctrl + B` | 添加/删除书签 |
| `Ctrl + F` | 聚焦搜索 |
| `Ctrl + G` | 跳转到行 |
| `Ctrl + S` | 导出过滤结果 |
| `F3` | 下一个搜索结果 |
| `Shift + F3` | 上一个搜索结果 |
| `Enter` | 下一个搜索结果（搜索框聚焦时） |
| `Escape` | 关闭当前面板 |
| `↑ / ↓` | 上/下一行 |
| `PageUp / PageDown` | 上/下一页 |
| `Home / End` | 首行/末行 |
